# Launch checklist

## Release gate
- Stability: each platform's crash rate must be below 1% of test sessions before release.
- Run the stability check in every beta round.

## Owners
- Android stability issues: Rin.
- iOS build and store review: launch team.

## Before announcing
- [ ] Store listing approved for each platform being released
- [ ] Each platform being released has passed the stability gate
- [ ] Release notes written
