## Measurement boundaries

- Vercel reports visitors, pageviews and referrers. The exporter includes observed social/video referrers; source rows are not additive unique people.
- Umami receives only registry-approved campaign labels on existing click/signup events. Free dashboard evidence still requires an authenticated read; Vercel free custom-event reporting is unavailable.
- Resend receives bounded first-landing fields only when its production feature flag is enabled and the contact write succeeds. They are client-reported context, not authenticated identity attribution.
- First-landing context is valid for 30 minutes in this tab's sessionStorage, then replaced on the next capture; there is no persistent visitor ID. Do Not Track disables optional capture/events.
- GitHub traffic is a separate rolling-14-day capture. Download counts are cumulative per release asset, not completed installs; stars cannot be joined to visitors.
- Before publishing, record the exact UTC time, channel, actual post URL, and snapshot paths. Read again at 24h, 72h and 7d. No schedule or external publication is created by this file.
