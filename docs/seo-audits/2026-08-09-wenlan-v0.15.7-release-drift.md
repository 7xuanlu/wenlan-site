## Decision

## Exact queued correction

1. Update the single release contract in `src/lib/releases.ts` to
   `v0.15.7`, publication date `2026-08-09`, exact tagged setup/release URLs,
   and verified current sizes.
2. Keep all four runtime downloads. Add the Apple Silicon desktop preview as
   a distinct user-facing DMG option on the full Download page; do not expose
   the signed updater tarball as a duplicate manual-download row.
3. For macOS Apple Silicon, make the homepage system recommendation the
   desktop DMG because it is now the maintained UI path. Label it clearly as
   a preview and surface the not-notarized boundary plus inspectable safe
   installer path. Keep the headless runtime available on the full Download
   page for CLI-only users.
4. Update English, zh-TW, and zh-CN release labels, descriptions, action
   labels, explicit setup links, and translation source hashes. Do not claim
   a Windows desktop app: the public Windows asset remains the runtime ZIP.
5. Update the English security current-stable line, changelog title/date/
   answer/highlights, About social footer, and relevant sitemap freshness.
   Describe the `v0.15.7` app-bundle changes accurately; retain older versions
   only where they are historical release entries.
6. Extend the release tests so the newest macOS DMG and the four runtime
   assets are all contract-bound. A blind version substitution is
   insufficient.

This is a correctness and download-UX repair, not a search experiment. It
must not receive impression, click, visitor, outbound, download, signup, or
star attribution.
