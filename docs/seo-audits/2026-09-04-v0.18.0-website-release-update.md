## Version-check correction

The old source tests chose the highest local Git tag, which can refer to a prerelease with incomplete assets. Source tests now inspect the exact tag selected in `src/lib/releases.ts` and fail if that tagged source cannot be read, without silently substituting the working tree.

`pnpm seo:release:check` separately reads GitHub's live latest-stable endpoint and verifies publication status, tag, timestamp, release URL, all six download URLs/states/sizes, and required updater/checksum assets. It fails on a prerelease, a newer stable release than the selected one, missing assets, size mismatch, or unavailable evidence. AGENTS.md routes release/download updates through this check before publication. Offline source-test success alone is not proof of freshness.
