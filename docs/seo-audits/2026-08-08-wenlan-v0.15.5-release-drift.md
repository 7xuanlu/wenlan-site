# Wenlan v0.15.5 Public-Release Drift — 2026-08-08

## Decision

The public site must be aligned from Wenlan `v0.15.3` to the current stable
`v0.15.5` release in a standalone technical correction. Do not combine its
deployment with the active source-backed snippet experiment; a combined
production boundary would make the search-copy readout less attributable.

This record defines the repair scope only. It does not authorize or perform a
website edit, commit, push, PR, merge, deployment, indexing request, Search
Console validation, or external publication.

## Authoritative evidence

- The sibling Wenlan checkout's latest stable tag is `v0.15.5`.
- Tagged `version.txt` is `0.15.5` and tagged `CHANGELOG.md` dates the release
  `2026-08-04`.
- GitHub Release `v0.15.5` is public and non-prerelease, published at
  `2026-08-05T00:11:32Z`.
- Wenlan release PR #484 for `0.15.6` merged at `2026-08-09T01:00:19Z`, but
  GitHub still reports `v0.15.5` as the latest release and no `v0.15.6` tag
  exists. A fresh GitHub REST read at `2026-08-09T01:40:19Z` returned HTTP 404
  for both the `v0.15.6` tag and release endpoints while the latest-release
  endpoint still returned public, non-prerelease `v0.15.5` with six assets.
  Do not publish an unreleased `0.15.6` website claim.
- Read-only HEAD checks followed the release redirects and returned HTTP 200
  for `wenlan-darwin-arm64.tar.gz`, `wenlan-linux-x64.tar.gz`,
  `wenlan-linux-arm64.tar.gz`, and `wenlan-windows-x64.zip`.
- A fresh production fetch of `https://wenlan.app/download` still contains
  `0.15.3` and does not contain `0.15.5`.
- The repository's full SEO suite passes 219 of 222 tests. Its three failures
  are the current-release contract, security current-stable line, and public
  release surfaces; the active snippet change does not touch those assertions.

## Exact correction surface

1. `src/lib/releases.ts`
   - change version/tag/download/setup URLs to `0.15.5`;
   - set `publishedAt` to the tagged changelog date `2026-08-04`;
   - update displayed binary sizes from the GitHub asset bytes: Windows
     `73.0 MB`, macOS `49.6 MB`, Linux x64 `63.5 MB`, Linux ARM64 `62.5 MB`.
2. `src/i18n/content/en.ts`, `src/i18n/content/zh-TW.ts`, and
   `src/i18n/content/zh-CN.ts`
   - update release labels, runtime descriptions, explicit download links,
     and release links without changing the supported-platform contract.
3. `src/app/(en)/docs/docs.ts`
   - update the security current-stable line;
   - make the changelog title keywords, date, current answer, highlights, and
     unreleased boundary describe `v0.15.5` accurately rather than performing
     a blind version substitution;
   - retain `v0.15.3` as release history only where historically useful.
4. `src/app/(en)/about/opengraph-image.tsx`
   - update the visible release footer.
5. `src/app/sitemap.ts`
   - advance About and Get Started last-modified dates to at least the tagged
     release date.

No other public text file currently contains the old exact `0.15.3` token.
Machine-readable structured data already reads `WENLAN_RELEASE`, so correcting
the single release contract updates its version and download URL without a
second hard-coded value.
